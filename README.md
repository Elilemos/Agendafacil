# AgendaFácil

Sistema de agendamento online para salões de beleza, barbearias e profissionais de estética.

## Objetivo

Permitir que clientes consultem serviços e horários disponíveis e solicitem agendamentos. O proprietário poderá administrar os serviços e a agenda.

## Funcionalidades planejadas

- Cadastro de serviços.
- Configuração dos horários de funcionamento.
- Consulta de disponibilidade.
- Criação, atualização e cancelamento de agendamentos.
- Painel administrativo.
- Notificações pelo WhatsApp.

## Tecnologias planejadas

- JavaScript, Node.js e Express.
- PostgreSQL e Prisma.
- React e Vite.
- Docker e Docker Compose.
- Vitest e Supertest.

## Status

Projeto em fase inicial de planejamento.
